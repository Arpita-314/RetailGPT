## Highlighted Projects

### [Chai Junction](chai%20junction/)
**Full-stack chai ordering web app** — React 18 + TypeScript frontend (MUI, Redux Toolkit, React Router), Node.js/Express TypeScript backend, MongoDB, JWT auth, Stripe payments, Cloudinary image storage.

### [LLM Fine-Tune Pipeline](LLM_project/llm-finetune-pipeline/)
**Production-minded MLOps pipeline** — ETL to sharded Parquet, distributed fine-tuning of DeBERTa/RoBERTa with LoRA + DeepSpeed, quantized inference via FastAPI/Ray Serve, W&B/MLflow monitoring hooks, Docker Compose.

### [FOAML — Fourier Optics AutoML](foaml/)
**GPU-accelerated simulation framework** — FDTD + ray tracing engines in C++/CUDA, FastAPI REST API, PyTorch ML models, Optuna hyperparameter optimization, plugin system, MLflow experiment tracking.

### [GPT from Scratch](gpt%20from%20scratch/)
**Micrograd neural network** — backpropagation engine and autograd system implemented from scratch in Python, following Karpathy's micrograd.

### [PINN — Physics-Informed Neural Networks](PINN/)
**PyTorch demo** — neural network solving projectile motion ODEs using physics-informed loss functions.

### [FNO-MagSolve](FNO-MagSolve/)
**Fourier Neural Operator** for NV magnetometry dataset generation and training.

### [ML Training — Brain Tumour Classification](ML_training/)
**Deep learning curriculum** — five-lesson sequence (L1–L5) covering CNNs, transfer learning, and reconstruction algorithms on a brain MRI dataset.
